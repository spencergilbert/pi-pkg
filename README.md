# pi-pkg

Personal [Pi](https://pi.dev) package — extensions, skills, prompts, and themes.

## Extensions

- [goal.ts](./extensions/goal.ts) - long-running objective mode with automatic continuation.
- [notify.ts](./extensions/notify.ts) - sends a native terminal notification (OSC 777) when Pi finishes and is waiting for input.

## Prompts

- [plan](./prompts/plan.md) - lightweight discussion and planning mode for exploring a topic before doing any work.

## Skills

- [commit](./skills/commit/README.md) - commit changes with a message matching the repository's own conventions.
- [github](./skills/github/README.md) - use the `gh` CLI when interacting with GitHub.
- [gitlab](./skills/gitlab/README.md) - use the `glab` CLI when interacting with GitLab.
- [kagi](./skills/kagi/README.md) - web search and extraction via the Kagi API.
- [plan-audit](./skills/plan-audit/README.md) - audit flat-rate AI coding subscriptions against session logs, reconciled with provider-reported quota.
- [tangled](./skills/tangled/README.md) - use the `tg` CLI when interacting with Tangled.
